# Icke-funktionella testfall
# TC-21 – Responsiv design
## Relaterat NFR:
NFR-02, NFR-14
## Förutsättningar:
Spelet går att öppna på olika typer av enheter.
# Steg:
1. Öppna spelet på en mobil.
2. Öppna spelet på en dator.
3. Starta och spela en match.
# Förväntat resultat:
* Spelplanen och knapparna fungerar på både mobil och dator.
* Viktig information hamnar inte utanför skärmen.
