# TC-25 - Avsluta och spara pågående match, state sparas

## Relaterat UC:

UC-08

### Förutsättningar

Användaren befinner sig i ett pågående spel och har godkänt lagring av cookies.

# Steg

1. Spelaren befinner sig i en pågående match.
2. Spelaren går till menyn och väljer "Spara och avsluta".
3. Pågående parti sparas och avslutas.

# Förväntat resultat

Spelet fryser när spelaren har valt "Spara och avsluta". Spelet avslutas och state sparas.
