# TC-26 - Avsluta pågående match, state sparas inte

## Relaterat UC:

UC-08

### Förutsättningar

Användaren befinner sig i ett pågående spel och har nekat lagring av cookies.

# Steg

1. Spelaren befinner sig i en pågående match.
2. Spelaren går till menyn och väljer "Spara och avsluta".
3. Pågående parti avslutas, men state sparas inte.

# Förväntat resultat

Spelet fryser när spelaren har valt "Spara och avsluta". Spelet avslutas, men state sparas inte.
